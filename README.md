# RPG Point Buy Calculator

Calculadora de atributos para Dungeons & Dragons 5e / 5.5.

## Recursos

- Point Buy de 30 pontos
- Valores de 5 a 20
- Modificador automático
- Custo atual e próximo custo
- Feedback visual por cores
- Barra de progresso
- Copiar distribuição
- Interface responsiva

## Tecnologias

- Angular 20
- TypeScript
- SCSS
